SEAM · Self-Evolving Agentic Migration for Chinese GPUs

让 CUDA 项目 迁移到国产 GPU
更简单

SEAM 是一个自动化迁移 AI 工具，能把原本只能在 NVIDIA 显卡上运行的 AI 项目， 自动迁移到中国国产 GPU 算力卡上运行并调优 —— 不再需要人工逐行改代码、逐个查报错。

Pipeline

核心：八阶段自动化迁移流水线

由 YAML 状态机驱动 + 5 个持久化智能体协同，以目标 GPU 上的真实运行反馈闭环迭代。

PHASE 01

GPU 环境检测

检测 Python / PyTorch 版本、目标 GPU 是否可用、厂商软件栈是否存在，确认具备迁移与运行条件。

PHASE 02

用户项目分析

解析目录结构、依赖文件、入口脚本、CUDA 调用模式与自定义算子，决定走普通迁移还是 custom-op 路线。

PHASE 03

依赖准备

按平台策略准备虚拟环境、Python 包、目标平台 PyTorch 版本与厂商 SDK 依赖。

PHASE 04

规则迁移

确定性的代码迁移：替换设备调用方式、调整导入语句、修改通信后端，不依赖大语言模型自由生成。

PHASE 05

验证修复循环

执行入口脚本 → 捕获错误日志 → 分析错误类型 → 分派修复角色 → 修改项目 → 再次运行验证。

PHASE 06

自定义算子最终验证

严格校验编译产物、真实调用路径、是否回退 CPU、精度比对、性能报告与构建日志证据。

PHASE 07

迁移报告生成

输出端到端结果、改动清单、依赖与环境状态、算子适配情况、性能表现与失败卡点。

PHASE 08

经验评估与精炼

评估本次成功与失败案例，把有效适配方案提炼为可复用技能，供后续类似项目参考。

规则迁移先行 → 稳定可复现；验证修复循环 → 直到通过或达到迭代上限； 自定义算子关卡 → 七项证据全部满足才标记为「完整迁移通过」。 整个流水线共享上下文，每一次运行都以目标 GPU 上的真实执行结果作为唯一判据。

Quick Start

三步上手 SEAM

在真正要运行迁移结果的国产 GPU 环境中启动 SEAM，它才能基于真实硬件反馈完成检测、运行、修复与验证。

bash — 迁移一条命令搞定 
# 1. 下载与环境准备
git clone https://github.com/Fudan-SMI-lab/SEAM.git
cd SEAM
python3.10 -m venv .venv
source .venv/bin/activate
pip install -e "src/[dev,dashboard]"

# 2. 启动 OpenCode Server（默认 127.0.0.1:4098）
opencode serve --hostname 127.0.0.1 --port 4098

# 3. 运行迁移（在目标国产 GPU 环境中执行）
bash src/scripts/run_seam.sh /path/to/your_original_cuda_project \
  --server_type opencode \
  --server_url http://127.0.0.1:4098
步骤 1

进入国产 GPU 环境，准备待迁移项目

在目标国产 GPU 服务器或容器中（阿里 PPU / 昇腾 NPU / 沐曦 GPU），准备一个原本可在 NVIDIA CUDA 环境运行的 AI 项目仓库。首次测试建议选规模较小、入口清晰的项目。

步骤 2

启动 OpenCode Server

默认地址 http://127.0.0.1:4098。端口不同时通过 --server_url 指定，也可以由 SEAM 自动启动（前提是已安装 opencode 并配好 Token API Key）。

步骤 3

运行迁移并查看结果

迁移结束后终端会显示是否通过端到端验证（E2E TEST PASSED）。报告位于 migration_reports/，日志位于 .sm-artifacts/。
