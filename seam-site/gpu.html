SEAM 已适配国产 GPU

SEAM 面向国产 GPU 和异构加速平台，帮助用户将原本依赖 NVIDIA CUDA 的 AI 项目迁移到目标平台运行。 当前已在三家平台上完成规模化适配验证。

Why Migration

兼容 ≠ 能跑：为什么不同 GPU 仍需适配

即使某些国产 GPU 声称兼容 CUDA，也不代表所有 CUDA 项目都能直接运行。

迁移不是简单的文本替换

  • CUDA API 与目标平台接口存在差异
  • PyTorch 后端和设备管理方式不同
  • 厂商驱动、SDK、编译工具链各不相同
  • 自定义 CUDA 算子可能没有现成等价实现
  • 项目依赖版本与目标平台软件栈不匹配
  • 性能调优策略与底层硬件架构强相关

因此，迁移需要结合真实硬件环境进行运行验证和修复， SEAM 需完成算子替换、底层调度逻辑改写、性能调优，兼顾可用性与实际运行性能。

平台策略差异

原生转换型（如部分 NPU 平台）

SEAM 可能需要将 CUDA 相关调用转换为目标平台专用接口。

CUDA 兼容型（如 PPU）

部分 torch.cuda 调用可能需要保留，因为目标平台通过兼容层支持相关接口。

SEAM 会根据目标平台策略选择对应迁移方式，并在运行过程中通过验证器检查迁移结果是否真实有效。
