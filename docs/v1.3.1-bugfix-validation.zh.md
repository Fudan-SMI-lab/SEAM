## 本次改动

1. **SGLang / Phase 5 派发缺失**：空值、未知角色或未配置的路由产生 `invalid_dispatch_route`，保存可选路由和错误原因，停止当前修复循环。先前 smoke test 的退出码 0 不再覆盖派发失败。Review Gate 改进失败保留 `improvement_error` 语义。
2. **凭证写入依赖 Linux procfs**：非 Linux POSIX 系统使用目录描述符相对读写、独占锁、原子发布及失败回滚。父目录被替换不会重定向写入；Linux 原路径和 Windows 路径保留。
3. **macOS 报告目录发布**：使用 Darwin `renamex_np(RENAME_EXCL)`，保持原子且不覆盖已有目录。
4. **Review Gate 证据丢失**：原实现将 `ReviewGate` 对象直接交给 JSON 编码，Phase 5 成功后可能留下无法解析的报告/检查点。现按结构化字段保存 review rounds，未知类型仍报错，不转换为不可审计的字符串。
5. **PPU 缺构建依赖的处理指导**：补充 `setuptools>=77.0.3`、PEP 517 隔离构建的诊断、受认可 wheelhouse/镜像、固定构建工具版本及失败说明；禁止用全局公共额外索引覆盖厂商运行时。此项为提示词流程完善，尚未完成目标机器实测。
6. **回归测试夹具与 CI**：虚拟环境使用 POSIX 符号链接，避免 uv Python 复制后缺动态库；运行时测试补齐实际报告文件，生产报告完整性检查保留；CI 增加 `v1.3.1` push 触发。
